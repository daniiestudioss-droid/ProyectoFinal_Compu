# ProyectoFinal_Compu
Nuestro Espacio Digital v2.0 es un sitio web creado por estudiantes para presentar sus perfiles vocacionales, habilidades, intereses y metas profesionales. Esta versión incorpora mejoras técnicas como CSS externo, diseño responsivo para móvil, tablet y computadora, navegación optimizada y una apariencia visual más atractiva y organizada.
